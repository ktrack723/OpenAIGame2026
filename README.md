# BISHOUJO RIZZ SIMULATOR 2077

브라우저에서 도는 3D 연애 **코칭** 게임. 당신은 연애하지 않는다 — 남을 연애시킨다.

three.js + 정적 파일만으로 만들어져 GitHub Pages 에 그대로 올라간다. 빌드 단계가 없다.

> 2077년. 출생률이 1 아래로 떨어졌고, 정부는 연애 경험이 없는 시민들이 짝사랑 상대에게
> 말을 걸도록 돕는 비밀 기관을 세웠다. 당신은 그 기관의 신입 요원이다.

---

## ⚠️ LLM 연결이 필수다

**오프라인 모드는 없다.** 의뢰인도, 상대도, 판정도 전부 모델이다.
API 키가 없으면 접속 화면에서 더 나아가지 않고, 대화 중 호출이 실패하면 그 자리에 멈춘다.
대체 판정으로 조용히 넘어가는 경로는 코드에 존재하지 않으며, 그 사실을 테스트로 못박아 두었다.

첫 화면에서 Anthropic API 키를 넣으면 연결을 확인한 뒤 시작한다.

- 키는 **브라우저 localStorage 에만** 저장되고 이 저장소의 어떤 서버로도 가지 않는다.
  호출은 브라우저 → `api.anthropic.com` 직접이다.
- 호출 비용은 본인 계정에 청구된다. **공용 기기에서는 쓰지 말 것.**
- 키 발급: [console.anthropic.com](https://console.anthropic.com/settings/keys)

브라우저에서 직접 부르기 위해 Anthropic 이 공식 지원하는
`anthropic-dangerous-direct-browser-access` 헤더를 쓴다. 모델은 기본 `claude-opus-5`
(접속 화면에서 변경 가능).

## 하는 일

| 단계 | 내용 | 입력 |
|---|---|---|
| 1. 서류철 | 의뢰인 6명 중 하나. 사연·외모·성격·상대의 취향(일부만 공개) | 탭 |
| 2-1. 스타일링 | 상대 취향에 맞게 꾸민다 — **적는 즉시 3D 모델이 바뀐다** | 자유 서술 |
| 2-2. 코칭 | 어떻게 대화할지. 그대로 의뢰인의 시스템 프롬프트가 된다 | 자유 서술 |
| 2-3. 격려 | 연설. 사연을 정확히 짚을수록 자신감이 오른다 | 자유 서술 |
| 3. 문자 단계 | 6번의 주고받기. **개입 1회** | 귓속말 |
| 4. 대면 단계 | 8번의 주고받기. **개입 2회**. 수치는 그대로 이어진다 | 귓속말 |
| 5. 편지 | 며칠 뒤 의뢰인이 결과를 편지로 알려온다 | — |

### 두 개의 수치

- **분위기** — 대화 흐름이 자연스러웠는가. 취향 적중과 무관하다.
- **호감** — 상대의 취향을 만족시켰는가. 대화 흐름과 무관하다.

**분위기는 호감 증감의 배율**이다 (0 → ×0.65, 100 → ×1.25).
어색하게 말했지만 취향을 맞혔다면 분위기 ▼, 호감 ▲ 가 정상이다.
분위기와 호감은 조명·안개·두 사람 사이의 거리로 무대에도 그대로 나타난다.

### 이기는 법

1. 공개된 취향은 스타일링과 코칭으로 미리 심는다.
2. 숨은 취향은 대화 중 상대가 흘릴 때만 드러난다.
3. **발견했으면 개입해서 알려줘야 쓴다.** 의뢰인은 긴장해서 스스로 눈치채지 못한다.
4. 같은 얘기를 반복하면 값이 급감한다. 넓게 훑어라.
5. 지뢰는 끝까지 비공개다. 코칭에 `자랑은 하지 마` 라고 적어두면 실제로 덜 밟는다 —
   부정문을 구분해서 읽는다.

## 텍스트가 곧 3D 모델

스타일링 칸에 적는 문장이 그대로 캐릭터의 생김새가 된다. 외부 모델 파일은 하나도 없고,
`web/three/appearance.js` 가 문장을 특징 명세로 바꾸면 `character.js` 가 프리미티브로
다시 조립한다. 글자를 고치면 모델이 즉시 다시 세워진다.

읽는 것들:

| 갈래 | 예 |
|---|---|
| 옷 | 후드티 · 정장 · 원피스 · 재킷 · 셔츠 · 니트 · 나시 |
| 머리 | 긴 머리 · 단발 · 포니테일 · 삭발 · 부스스한 · 올림머리 |
| 색 | 검정 · 흰 · 빨강 · 분홍 · 네이비 · 은색 · 형광 … (가장 가까운 명사에 붙는다) |
| 체형·자세 | 큰 키 · 작은 키 · 넓은 어깨 · 마른 · 구부정한 · 꼿꼿한 |
| 소품 | 안경 · 헤드폰 · 목걸이 · 피어싱 · 타투 · 모자 · 목도리 · 시계 · 부츠 · 우산 · 앞치마 · 가방 · 사원증 |

`분홍 머리, 검정 재킷` 처럼 색이 둘이면 **명사에 더 가까운 색**이 붙는다.
서류철의 고정 외모(`항상 후드티`, `구부정한 어깨` …)가 기본값이 되고, 스타일링이 그 위를 덮는다.

## 모바일 / 아이패드

- 세로 화면에서는 카메라가 뒤로 빠지고 화각이 넓어져 두 사람이 모두 들어온다.
- 버튼은 최소 48px 높이. 입력 글자는 16px 이상이라 iOS 가 자동 확대하지 않는다.
- `viewport-fit=cover` + `safe-area-inset` 으로 노치·홈 인디케이터를 피한다.
- 픽셀비는 2로 묶어 고해상도 기기에서 과도하게 그리지 않는다.
- UI 는 WebGL 캔버스 위의 DOM 오버레이다 — 탭 타깃·키보드·접근성이 브라우저 기본으로 따라온다.

세로/가로, 아이폰·아이패드 뷰포트는 E2E 테스트가 매번 확인한다.

## 실행

```bash
npm install          # 테스트용 (게임 자체는 의존성 0)
npm start            # http://127.0.0.1:4173
```

`index.html` 을 정적으로 서빙하기만 하면 된다. three.js 는 `vendor/` 에 함께 들어 있어
CDN 이 막혀도 뜬다.

### GitHub Pages 배포

`.github/workflows/pages.yml` 이 테스트를 돌리고 통과하면 Pages 로 올린다.
저장소 **Settings → Pages → Source** 를 **GitHub Actions** 로 바꾸면 끝이다.

## 테스트

```bash
npm test          # Node 단위·통합 (65개)
npm run selfplay  # 자동 플레이 계측
npm run test:e2e  # 브라우저 E2E — 데스크톱 · 아이패드 · 아이폰
npm run test:all  # 전부
```

E2E 는 `api.anthropic.com` 을 가로채 가짜 모델로 바꿔치고 **실제 fetch 전송 계층부터
구조화 출력 파싱, 게임 루프, DOM, WebGL 렌더까지 그대로 통과시킨다.** 바꿔치는 건 모델뿐이다.

확인하는 것들:

- 키 없이는 게임이 시작되지 않는다 / 연결 실패 시 접속 화면에 머문다
- 브라우저 직접 호출 헤더와 Opus 5 요청 규격 (`temperature`·`thinking` 미포함, `output_config.format`, 캐시 분기점)
- WebGL 캔버스가 실제로 픽셀을 칠한다
- 스타일링 문장을 바꾸면 모델 명세가 실제로 달라진다
- 한 판이 14턴을 돌아 성공/실패 엔딩까지 간다
- 대화 도중 호출이 끊기면 **멈추고** 재시도를 제안한다 (대체 판정 없음)
- 세로 화면 탭 타깃 크기 · 가로 스크롤 없음 · 입력 16px

### 자동 플레이 계측

`tools/selfplay.js` 는 `test/helpers/fake-model.js`(결정적인 가짜 상대)를 붙여 돌린다.
실제 게임은 LLM 로 돌지만, 밸런스와 루프는 고정된 상대가 있어야 계측이 된다.

승률 (60판/칸, 고백 성공):

| 전략 | 쉬움 | 보통 | 어려움 |
|---|---:|---:|---:|
| 숙련 요원 (준비 + 개입) | 100% | 100% | 77% |
| 평범한 요원 (준비만) | 100% | 88% | 50% |
| 날림 요원 | 2% | 0% | 0% |
| 무준비 / 역효과 | 0% | 0% | 0% |

`test/balance.test.js` 가 이 수치를 회귀 테스트로 고정한다.

## 구조

```
index.html           Pages 진입점 (importmap · 빌드 없음)
vendor/              three.js (동봉)
web/
  main.js            화면 흐름
  ui.js              DOM 조립 헬퍼
  styles.css         네온 스킨 · 반응형
  three/
    scene.js         무대 · 조명 · 카메라(세로/가로)
    character.js     명세 → 프리미티브 캐릭터
    appearance.js    외모 텍스트 → 특징 명세  ← 텍스트가 모델이 되는 지점
game/
  core/              상태 기계 · 채점 · 밸런스 상수 · 시드 난수
  engine/            Messages API 호출 · 세 역할 프롬프트
  data/              의뢰인 6명 · 화제 19종 · 지뢰 7종 · 엔딩 편지
test/
  *.test.js          Node
  e2e/               Playwright (가짜 API 포함)
  helpers/           가짜 모델 (테스트 전용 — web/ 에서 import 되지 않는다)
tools/
  serve.js           정적 서버
  selfplay.js        자동 플레이 계측
```

세 개의 역할이 각각 한 번의 API 호출이다.

- **의뢰인** — 코칭·격려·개입을 받아 말한다. *상대의 취향 목록을 절대 보지 못한다.*
- **상대** — 자기 취향을 전부 알고, 가끔 힌트를 흘린다.
- **심판** — 의뢰인의 매 발언을 분위기/호감 증감으로 환산한다 (JSON Schema 구조화 출력).

정답지가 의뢰인 프롬프트로 새지 않는 것은 테스트로 강제된다.
